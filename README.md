# Tic Tac Toe

A fully responsive Tic Tac Toe game built with vanilla HTML, CSS, and JavaScript. Play against a friend or challenge an unbeatable AI powered by the minimax algorithm.

## ✨ Features
- **Two Game Modes**: 2-player mode (X vs O) or single-player vs AI.
- **Unbeatable AI**: Minimax algorithm ensures perfect play (AI plays as O, you as X).
- **Win/Draw Detection**: Automatic game end with winner announcement or draw.
- **Responsive Design**: Works on desktop, tablet, and mobile (optimized with media queries).
- **Smooth UX**: Click-to-play, reset button, mode toggle, disabled states.
- **No Dependencies**: Pure vanilla JS – instant load, no build step.

## 🎮 How to Play
1. Open `index.html` in any web browser.
2. Toggle **AI Mode** or **2 Player Mode** using the button.
3. Click on grid boxes to place your mark (X in AI mode).
4. AI responds instantly in AI mode.
5. Game ends on win/draw – click **Restart** to play again.

### Controls
- Click boxes to play.
- `#modeToggle`: Switch modes.
- `#resetbtn`: New game.

## 🛠️ Tech Stack
- **HTML5** for structure
- **CSS3** Flexbox, animations, responsive design
- **Vanilla JavaScript** for logic, minimax AI algorithm

## 🚀 Quick Start
1. Clone/Download the repo.
2. Open `index.html` in your browser.
3. Play!

# Windows
start index.html

# Or drag index.html to browser
